About ShopEasy

ShopEasy is a mini e-commerce website made as a college project to practice HTML, CSS and JavaScript. The main aim of this project was to understand how a basic online shopping website works, including things like product listing, cart management, and a simple login/register system.


This project does not use any frameworks like React or Bootstrap. Everything is built using plain HTML, CSS and JavaScript, and data (like users and cart items) is stored using the browser's Local Storage instead of a real database or backend server.


Features included in this project: product browsing, search and category filter, product details page, shopping cart with quantity control, checkout with shipping details, and a login/register system.
